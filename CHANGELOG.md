# Changelog

Toutes les modifications notables de NB Menu démarrer WP sont documentées ici.

Le projet suit la numérotation [Semantic Versioning](https://semver.org/lang/fr/).

## [1.1.0] - 2026-07-28

### Ajouté

- anglais défini comme langue source de l’extension, conformément aux pratiques WordPress ;
- traduction française complète fournie dans l’archive ;
- documentation GitHub disponible en anglais et en français.

### Compatibilité

- aucun identifiant technique ni aucune préférence enregistrée n’est modifié ;
- les sites configurés en français conservent automatiquement l’interface française.

## [1.0.1] - 2026-07-28

### Modifié

- nouvelle identité publique : **NB Menu démarrer WP** ;
- mise à jour de la documentation, des archives de publication et des liens GitHub ;
- conservation des identifiants techniques historiques afin de préserver les installations et les préférences existantes.

## [1.0.0] - 2026-07-28

### Ajouté

- première version stable destinée à une diffusion publique ;
- catalogue de traduction WordPress ;
- contrôles automatiques de syntaxe, de sécurité, de poids et de cohérence des versions ;
- génération automatique d’un ZIP installable lors de chaque publication GitHub ;
- documentation de fonctionnement, de confidentialité et de contribution.

### Modifié

- tous les textes de l’interface JavaScript utilisent désormais le système de traduction WordPress ;
- documentation d’installation et d’utilisation clarifiée.

### Sécurité

- conservation des préférences limitée au compte WordPress connecté ;
- contrôle du nonce et validation stricte des données avant sauvegarde ;
- aucun appel à un service tiers, aucune télémétrie et aucun secret embarqué.

## [0.2.2] - 2026-07-24

- maintien des sous-menus à l’intérieur du lanceur sur toutes les tailles d’écran.

## [0.2.1] - 2026-07-24

- maintien du lanceur ouvert lors de la modification des favoris.

## [0.2.0] - 2026-07-24

- ajout des raccourcis URL personnalisés ;
- correction de la persistance des favoris et dossiers ;
- sauvegarde renforcée lors des changements de page.

## [0.1.0] - 2026-07-24

- première version fonctionnelle.
